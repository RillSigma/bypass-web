Redirect standar

Jika tautan mengirim redirect HTTP biasa, browser akan mengikuti pengalihan tersebut secara normal.

Privasi

Tautan dibuka langsung di browser Anda. Halaman ini tidak mengirim URL ke layanan pemeriksa pihak ketiga.

Bagaimana jika belum sampai ke tujuan?

Situs mungkin menampilkan halaman perantara atau meminta tindakan manusia. Ikuti petunjuk resmi yang terlihat di browser. Jangan masukkan kata sandi atau mengunduh file jika Anda tidak yakin dengan sumbernya.

Bisa dipasang seperti aplikasi di HP?

Di browser yang mendukung PWA, gunakan menu browser lalu pilih “Tambahkan ke layar utama” atau “Install app”. Website ini juga tetap bisa dibuka seperti biasa tanpa instalasi.
